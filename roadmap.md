# Full Stack Study Plan — BCA 2nd Year → Job Ready

**Starting point:** Just began HTML, no CSS yet, basic Python knowledge
**Constraint:** Full-time college (9–5), commute via bus, focus drops after 30–60 min
**Fixed:** 4:00 am wake-up, 6 hours sleep max

---

## Daily Routine (Weekdays)

| Time | Activity |
|---|---|
| 4:00 am | Wake up, freshen up |
| 4:15 – 6:00 am | **Study Block 1** — two 45-min sessions |
| 6:00 – 7:00 am | Get ready, breakfast |
| 7:00 am | Leave for college (bus) |
| 9:00 – 5:00 pm | College |
| 6:30 pm | Reach home |
| 6:30 – 8:00 pm | Rest, dinner, decompress |
| 8:00 – 9:40 pm | **Study Block 2** — two 45-min sessions |
| 9:40 – 10:00 pm | Wind down, no screens |
| 10:00 pm | Sleep |

10 pm – 4 am = 6 hours sleep, non-negotiable — protect the bedtime even on heavy days.

---

## Exactly What Goes in Each Slot

Every week below lists **one specific subtopic**. That subtopic is what fills the day's sessions — she should never have to decide "what do I study now," just open the plan and see the topic for that day.

**How to split a week's topic across the day (example using Phase 1, Week 1: HTML tags & structure):**

| Slot | What to actually do |
|---|---|
| Block 1 – Session 1 (4:15–5:00) | Watch that day's tutorial portion on the week's topic (e.g., HTML semantic tags video) |
| Block 1 – Session 2 (5:05–5:50) | Immediately code along / rewrite what was just watched from memory — no copy-pasting |
| Block 2 – Session 1 (8:00–8:45) | Apply the topic: build a small piece of that week's project using it, or do extra practice exercises |
| Block 2 – Session 2 (8:50–9:35) | **Mon/Wed/Fri → DSA problem (see phase notes)** · **Tue/Thu → revisit anything unclear from morning + write the 1-line daily log** |

This same pattern repeats every day — only the week's topic changes. A typical week (5 weekdays) covers one subtopic in real depth: watch → code along → apply → reinforce.

**Weekends:** see the dedicated Saturday/Sunday schedule below.

---

## Weekend Schedule (Saturday & Sunday)

Same anchors as weekdays — **4:00 am wake, 10:00 pm sleep** — but no college, so the day is shaped differently. Saturday is the heavier "build" day; Sunday is deliberately lighter, since Sunday is already the review day per the ground rules. Both days include real rest — an 18-hour day with no breathing room will burn her out on 6 hours of sleep.

### Saturday — Deep Work + Catch-up

| Time | Activity |
|---|---|
| 4:00 – 4:15 am | Wake, freshen up |
| 4:15 – 6:00 am | Project work — extend that week's project (2 × 45-min sessions) |
| 6:00 – 7:00 am | Breakfast, free time |
| 7:00 – 9:00 am | Project work continued OR catch-up if behind schedule (2 × 45-min sessions) |
| 9:00 – 9:30 am | Break |
| 9:30 – 11:00 am | Extended DSA — clear the week's problem set + 1–2 extra problems |
| 11:00 am – 1:00 pm | **Free time** — hobbies, rest, socializing, no screen-guilt |
| 1:00 – 2:00 pm | Lunch |
| 2:00 – 4:00 pm | Project work — push further on the week's build (2 × 45-min sessions) |
| 4:00 – 5:00 pm | Break — walk, exercise, outdoors |
| 5:00 – 6:30 pm | Light supplementary learning — docs, articles, or a related short video (optional, low-pressure) |
| 6:30 – 8:00 pm | Dinner, family/friend time |
| 8:00 – 9:30 pm | Push code to GitHub, update the daily/weekly log, tidy up the week's work |

## A Few Ground Rules

1. **Consistency > intensity.** Missing one day is fine. Missing a week breaks momentum.
2. **Don't skip ahead.** Each phase's project should exist before moving to the next phase.
3. **Sunday = lighter review day** — revise the week, fix bugs in old projects, DSA problem set review, no new core-topic material.
4. **Track it visibly.** A checklist with an X for each completed session.
